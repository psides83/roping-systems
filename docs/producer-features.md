# Producer feature preferences

Settings > Features controls optional staff navigation and selected workflow tools.
Missing preferences default to enabled. Owner/admin changes are audited and
revision-checked, and each producer has independent preferences. No records are
deleted. Direct links remain available for historical records and obligations.

Member records hide empty fines, suspensions, watch evidence, and bonus positions
when disabled. Existing records remain visible; fines can still be collected or
waived and suspensions lifted, but their new-issue buttons are hidden. Dues links
remain on members with dues records. Event qualification and bonus qualifier
controls remain when rules are already attached. Profitability remains on events
with expense history. Fund-backed sources and template fee choices are hidden for
new records, while existing contributions remain editable. Payout finalization
and external added money remain core tools.

Public navigation hides optional standings, rules, news, and membership links;
sponsor galleries are hidden when disabled. Direct public URLs still work and
already-open pages keep their current navigation label. Public preference reads
expose only public-facing keys, never staff-only preferences.

These are visibility preferences, not authorization or cancellation of existing
rules. Subsequent work must add online entries, portal, and competition-format
controls, and cover remaining setup forms/checklists and notifications. Existing
server permissions and eligibility checks remain authoritative.
