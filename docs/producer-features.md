# Producer feature preferences

First phase: Settings > Features controls optional staff navigation links.
Missing preferences default to enabled. Owner/admin changes are audited and
revision-checked, and each producer has independent preferences. No records are
deleted. Direct links remain available for historical records and obligations.

This phase does not disable workflows or hide public pages. Subsequent work must
connect preferences to event/member controls and public navigation, protect
unresolved obligations, and add online entries, fines, suspensions, profitability,
portal, and competition-format controls. Do not treat navigation visibility as
authorization; existing server permissions remain authoritative.
