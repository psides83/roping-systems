# In-App Notifications

Staff and ropers access their notification center through the bell. Notices can be filtered, marked read individually, or marked read a page at a time. Read status belongs to each user; reading a reminder does not resolve its underlying task.

Staff reminders reflect pending applications and online entries, unreviewed classification-watch flags, unpaid fines, and unresolved bonus positions. Access follows existing staff permissions, including arena-scoped timing access. Resolved reminders disappear; changed reminders become unread again.

Roper notices record accepted entries, event and roping schedule changes, and classification assignments from deployment onward. Bonus-position notices use the existing qualification calculations. Access requires a linked roper identity or approved membership link, never an email match alone.

The bell refreshes while the page is visible, on returning to the page, and after marking notices read. Failed refreshes display an unavailable indicator instead of implying there are no unread notices.

This release provides in-app notices only, not email, push delivery, or offline support. Existing historical changes are not backfilled.
