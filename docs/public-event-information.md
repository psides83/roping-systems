# Public event information

Event managers use **Public information** on Manage Event to add a flyer link,
directions and parking notes, venue information, entry instructions, and event
contact details. These details remain editable after competition starts and
changes are recorded in the changelog.

The public schedule keeps this information collapsed. Calendar event dialogs
show the same information. Existing event entry dates are shown in the producer's
time zone; this editor does not create a second deadline.

Flyers currently use an external HTTP/HTTPS link, including links to PDFs and
images. Google Maps and Apple Maps directions use the full event street address.
Maps are links rather than embedded maps, avoiding third-party loading and extra
visual clutter. A producer can provide special arrival instructions in the notes.

Public visitors can only read information for events in the published schedule.
Only staff with event management permission can modify it.
